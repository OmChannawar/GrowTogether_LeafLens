# 🌱 GrowTogether_LeafLens – Crop Disease Detection

GrowTogether AI is an AI-powered smart agriculture platform that helps farmers detect crop diseases from plant images and receive useful information about the detected disease and recommended treatment.

The system uses computer vision and deep learning techniques to analyze crop images and provide fast and intelligent disease detection.

## 🚀 Features

- 🌿 AI-based crop disease detection
- 📷 Upload crop/leaf images for analysis
- 🎯 Disease detection and localization
- 🧠 Deep learning-based classification
- 🤖 Gemini AI integration for additional analysis
- 📍 Location-based disease monitoring
- 🗺️ Interactive map-based visualization
- 📊 Disease detection results and analytics
- 💊 Treatment and prevention recommendations
- ⚡ FastAPI-based AI backend
- 💻 Modern React + TypeScript frontend

## 🛠️ Technologies Used

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Python, FastAPI
- **Machine Learning:** PyTorch, YOLOv8, EfficientNet, ResNet
- **Computer Vision:** OpenCV
- **Generative AI:** Google Gemini
- **Maps:** Leaflet
- **Database:** PostgreSQL / PostGIS
- **Tools:** Git, GitHub, VS Code
